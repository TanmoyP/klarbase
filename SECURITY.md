# Security

Found a security problem in Klarbase (the game at klarbase.dev, its API, or the CI that checks
pull requests)? Please **don't open a public issue**. Report it privately instead:

**GitHub → this repo → Security → Report a vulnerability.**

You'll get a reply within a few days. Once it's fixed, you're credited in the fix unless you'd
rather not be.

Things worth reporting: anything that leaks a player's data or session, lets someone publish or
delete an isle they shouldn't, shows a solution to someone who hasn't earned it through the
API, or makes the pull-request checks run code or see secrets.
